01 执行摘要

2026年是"十五五"规划开局之年，也是2027建军百年目标的关键窗口。军工板块业绩拐点已在2025Q4确认：2026Q1板块净利107亿元（+47.2%），中报预告49/69家预增。九三阅兵（9.3）、珠海航展（11月）、十五五规模化订单三大催化叠加，机构普遍判断军工从"杀估值"转向"等催化"，战略配置窗口显现。

核心结论一：军工板块业绩拐点确认——2026Q1营收1840.6亿（+19.4%）、净利107.1亿（+47.2%），结束连续四年下行。中报预告69家披露中49家预增。

核心结论二：三大催化叠加：九三阅兵（9.3，展示无人集群/高超音速等新装备）、珠海航展（11月）、十五五规模化订单下达。机构判断板块从"杀估值"转向"等催化"，战略配置窗口显现。

核心结论三：行业从"周期成长"转向"全面成长"，三条增长曲线：内需（基本盘）、军贸（新引擎）、军转民（新边界，商业航天/大飞机/低空经济）。

风险提示：订单落地不及预期、军品降价压力、业绩确认滞后、公募持仓仍处低位。

02 行业概览：从"周期成长"到"全面成长"

2.1 定义与范畴

国防军工行业覆盖航空、航天、船舶、兵器、电子等七大领域，产业链从上游材料/元器件→中游分系统→下游整机（主机厂）。2026年"大军工"概念崛起，范畴拓展到商业航天、低空经济、大飞机、军贸等军技民用新赛道。

2.2 三轮驱动新格局

1内需（基本盘） → 2军贸（新引擎） → 3军转民（新边界）
  • 第一曲线·内需："备战打仗"+装备现代化，国防预算稳定增长，强威慑高精尖+体系化无人化低成本
  • 第二曲线·军贸：性价比优势+体系化作战能力+一带一路，中国军贸份额持续提升
  • 第三曲线·军转民：商业航天、低空经济、大飞机、深海科技等万亿级新产业

2.3 行业本质

军工是典型的"订单驱动"行业——五年规划决定订单节奏，事件（阅兵/航展/地缘）催化情绪。核心变量是十五五规模化订单的下达节奏。

核心逻辑：2026年军工进入"十五五元年+建军百年倒计时"双重窗口，订单确定性显著增强。行业从"总量扩张"转向"结构优化"、从"预期炒作"转向"价值兑现"。

3.3 中报预告

截至2026年7月31日，69家军工上市公司披露中报，49家预增/增长、20家预减。增长点主要在船舶和军贸（中国船舶预计H1净利92-110亿，+212%~273%）。

业绩判断：板块从"业绩预期"转向"业绩兑现"。2026Q1净利+47%确认拐点，中报继续验证。但内部结构分化明显——船舶/导弹/地面兵装强，航空/航发/信息化弱。

04 核心催化：九三阅兵与十五五

4.1 九三阅兵（2026.9.3）

国务院新闻办确认9月3日在北京天安门举行抗战胜利80周年阅兵，编设45个方（梯）队，重点展示无人集群、高超音速导弹等新质作战力量。这是继2015年后又一次重大阅兵，将大幅提升市场对装备迭代与列装规模的关注。

4.2 珠海航展（11月）

两年一度的珠海航展是军工"事件窗口"，新装备展示+军贸订单签约，提供情绪与关注度修复契机。军贸订单有望集中披露（无人机、防空预警、红外等消耗类装备）。

4.3 十五五规划

2026年3月"十五五"规划纲要草案已提请人大审查，明确"如期实现建军百年目标"。参照历史，五年规划开局之年军工订单确定性增强——下半年规模化订单下达是核心催化。

催化判断：短期看九三阅兵（9月）事件驱动，中期看十五五订单下达（下半年），长期看2027建军百年目标。机构判断军工从"杀估值"转向"等催化"，战略配置窗口显现。

05 三条增长曲线

5.1 内需：新质战斗力

装备体系由机械化、信息化向智能化融合演进，核心方向：

  • 强威慑/高精尖：高超音速武器、三位一体核打击、防空反导、激光武器
  • 无人化/低成本：AI赋能装备、便于低成本大批量制造的无人系统
  • 导弹/弹药：全球冲突消耗巨大（俄乌/中东），低成本精确制导弹药补库需求

5.2 军贸：第二增长曲线

印巴5·7空战充分验证中国装备实战能力（歼-10CE+PL-15E击落阵风），叠加俄乌拖累俄军贸产能（俄份额21%→11%），中国军贸迎来补位机会。巴基斯坦占中国军贸出口51%，印尼等转向采购歼-10CE。无人机出口尤具优势（翼龙-1约100万美元，美MQ-1约400万）。

5.3 军转民：万亿新赛道

尖端军工技术向民用溢出，催生商业航天（可回收火箭+卫星组网）、低空经济（eVTOL）、大飞机（C919/CJ1000A）、深海科技、可控核聚变等万亿级产业。

主线判断军工投资四大方向：①传统军工修复（航空/导弹/船舶）；②大军工轮动（商业航天/民机/燃机）；③军贸出海（无人机/红外/弹药）；④军工电子（军事智能化+AI外溢）。

06 核心公司与标的

航空装备：中航沈飞 / 中航成飞 / 中航西飞 / 航发动力主机厂
沈飞：歼击机龙头，净利率突破5%（唯一超5%的主机厂）。成飞：战斗机龙头，7月市场震荡中逆势正收益。西飞：大型运输机+大飞机机体最大供应商。航发动力：航空发动机核心标的，长期看民航发动机国产替代。
导弹/弹药：高德红外 / 北方导航 / 国博电子消耗品
高德红外：大额订单公告+红外制导。北方导航：精确制导。国博电子：TR组件（有源相控阵雷达核心）。导弹2026Q1净利+133.6%，低成本精确制导是十五五重点。
船舶：中国船舶 / 中国重工 / 中国海防高景气
中国船舶：2026H1净利预增+212%~273%（92-110亿）。全球份额：新接订单占全球82.3%、手持订单71.2%。民船高景气+军船交付双轮驱动。
军工电子：火炬电子 / 航天电器 / 宏达电子 / 振华科技智能化
火炬电子：高端电容（MLCC），6月涨71.6%。航天电器：连接器+AI外溢配套。宏达电子：被动元器件。振华科技：军工电子平台。军工电子2025年净利+38%，是智能化最受益方向。
商业航天：中国卫星 / 航天电子 / 海格通信 / 中科星图大军工
逻辑：可回收火箭突破（长征十号乙一子级回收）+千帆/星网组网提速（在轨332颗）+卫星互联网批量生产。商业航天从事件题材切换为业绩成长主线。
标的思路：军工板块PE 59.5倍（事件催化期偏高），建议沿"业绩确定性+事件催化"双线配置：主机厂看订单兑现（沈飞/成飞/航发动力），弹性看导弹/船舶（中报验证），成长看军工电子（智能化）和商业航天（大军工）。

07 军工电子：智能化最受益

7.1 为什么军工电子最受益

装备体系正由机械化、信息化向智能化融合演进，感知、通信、指控、电子对抗、无人化协同等环节价值量持续提升。军工电子从传统配套属性，升级为装备体系升级中最清晰、最具成长性的方向。

7.2 业绩拐点

指标数据
2025年核心企业营收+24.14%（结束连续四年下行）
2025年归母净利润+38.08%
2026Q1营收/净利同比再度正增长
细分表现上游元器件回补最强，连接器稳健

7.3 三大需求共振

①军工智能化：装备升级的确定性增量；②AI外溢：军工企业以高可靠/自主可控优势切入国产算力、服务器、电力（连接器、MLCC、功率器件）；③商业航天：星载电子全链条需求（射频、电源、处理、传感）。

成长判断：军工电子兼具"军工底色+AI成长属性"，是下半年最具超额收益潜力的方向。重点看火炬电子（MLCC）、航天电器（连接器）、国博电子（TR组件）。

08 投资逻辑与风险

8.1 投资逻辑

主线一（传统修复）：航空装备（沈飞/成飞/西飞/航发动力）+导弹（高德红外/北方导航）——十五五订单+建军百年催化。

主线二（大军工）：商业航天（中国卫星/航天电子/海格通信）、民机（中航西飞/航发动力）、燃气轮机（应流股份/万泽股份）——催化密集、弹性强。

主线三（军贸）：中无人机/航天彩虹/国睿科技/中航西飞——印巴实战验证+珠海航展订单披露。

主线四（军工电子）：火炬电子/航天电器/宏达电子/振华科技——智能化+AI外溢双重逻辑。

主线五（船舶）：中国船舶/中国重工——中报高增验证（+212%~273%）。

8.2 风险提示

风险一：订单落地不及预期（中高风险）。军品订单受人事、规划节奏影响，十五五订单下达可能推迟。

风险二：军品降价（中风险）。军品采购低成本化趋势，上游材料和电子元器件毛利率已下滑1.4pct。

风险三：业绩确认滞后（中风险）。军工产品验收、定价机制导致回款慢，应收账款高企。

风险四：估值偏高（中风险）。中证军工PE 59.5倍，事件催化期估值已计入部分预期；公募持仓2.7%处历史低位（外资持仓创新高631亿）。
一句话总结：军工板块2026年"业绩拐点+事件催化"共振——九三阅兵（9月）短期催化、十五五订单（下半年）中期驱动、建军百年（2027）长期逻辑。投资沿"业绩确定性（船舶/导弹）+事件弹性（阅兵/航展）+成长方向（军工电子/商业航天）"配置。
