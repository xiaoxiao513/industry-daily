01 执行摘要

存储芯片是AI算力产业链中涨价弹性最大的环节，被称为"AI算力的燃料"。本报告是"AI算力产业链"系列第五篇，聚焦存储芯片（含HBM），从市场规模、供需格局、HBM技术、国产替代、投资逻辑五个维度展开。

核心结论一：存储芯片正经历AI驱动的"超级周期"。2026年全球存储市场预计5,516亿美元，同比+134%；DDR5现货价自2025年9月以来上涨约300%。

02 行业概览：AI算力的燃料

2.1 存储芯片的角色

存储芯片是AI服务器的"记忆中枢"，负责保存模型参数和中间计算结果。在AI算力体系中，存储决定了数据能否被快速读取——没有足够的存储带宽，再强的GPU也无法发挥性能。

2.2 AI对存储需求的拉动

维度需求倍数驱动因素
AI服务器DRAM用量传统服务器的8-10倍KV Cache动态膨胀
AI服务器NAND需求约普通服务器3倍训练数据存储
AI对NAND闪存需求提升12倍以上推理+多模态

2.3 存储价值量占比的飙升

以联想SR650 V4服务器为例：存储成本占比由2025年Q2的10%（DRAM 6%+NAND 4%）升至2026年Q2的32%（DRAM 22%+NAND 10%）。其中DRAM单价涨371%，NAND单价涨251%。存储正在从服务器的"配角"变为"主角"。

核心逻辑：AI训练和推理对内存带宽的需求是普通计算的数十倍。存储涨价 + 用量提升 = 存储环节量价齐升，是本轮AI周期中弹性最大的方向之一。

市场结构：DRAM占56%、NAND Flash占38%、其他占4%。HBM是增长最快的细分，2025年市场规模已超120亿美元。

3.2 为什么是"超级周期"

本轮存储周期与历史不同：

  • 需求端：AI算力爆发带来结构性增量，而非周期性复苏
  • 供给端：三大原厂集体退出/压缩DDR4，产能转向HBM和高端DDR5
  • 长约锁定：北美云厂商和国内模组厂已与原厂签订3-5年长约，周期能见度大幅拉长
  • 涨价节奏：2026年合约价全年上涨、涨幅逐季收窄，2027年至少保持高位
关键判断历史上存储是强周期行业，但本轮由AI结构性需求驱动，"周期属性"减弱、"成长属性"增强。行业已从"价格能涨多久"进入"高位能保持多久"阶段。

4.2 涨价幅度

现货价（2025年6月至2026年5月）：

  • DDR5 16Gb：涨幅624%
  • DDR4 8Gb：涨幅847%-1060%
  • 256GB服务器DDR5内存条突破5万元

合约价（2025年6月至2026年3月）：DDR4 8Gb涨400%、DDR4 16Gb涨436%。2026年Q1总DRAM合约价环比+93%~98%，Q2 +58%~63%。

4.3 紧缺的核心原因：HBM的"虹吸效应"

HBM生产存在约3:1晶圆产能消耗比（每生产1片HBM需消耗3片等效晶圆产能），大量消耗原厂的先进产能，挤压通用DRAM供给。叠加三星、SK海力士、美光、长鑫集体退出DDR4，产能向高端倾斜，通用DRAM供给收缩明显。

结构性矛盾：AI需求虹吸先进产能 → 通用DRAM供给收缩 → 全品类涨价。这种"AI带动+产能错配"的结构性紧缺，与历史上的单纯周期短缺有本质区别，持续时间更长。

5.3 HBM的竞争地位

HBM是存储行业技术壁垒最高的环节，也是本轮AI周期中利润最丰厚的领域。SK海力士凭借专有MR-MUF封装技术领先，HBM销售额已占其DRAM总销售额的40%。HBM的竞争不仅是存储原厂之间的较量，更深度绑定英伟达等GPU巨头的产品迭代。

投资含义：HBM是"AI的燃料"，其供需和技术格局决定了整个AI芯片的性能上限。跟踪HBM的量价与英伟达下一代GPU（Rubin）的绑定关系，是判断存储行业景气的核心指标。

06 国产存储：追赶与突破

长鑫存储（CXMT）DRAM国产龙头
进展：19nm DDR4规模化量产（良率超90%），单位晶圆成本较韩国厂商低15%-20%。2025年DRAM年产量273万片，跻身全球第四大DRAM厂商。2026上半年停供消费级DDR4，全力冲刺国产HBM。关键突破：已向华为交付HBM3样品。
长江存储（YMTC）NAND国产龙头
进展：全球首家量产232层3D NAND（Xtacking架构），位密度15.03 Gb/mm²。NAND出货量份额从年初约8%提升至14%。产品批量用于阿里云、腾讯云，"致态"品牌京东双11销量反超三星。

国产替代的政策与目标

  • 2027年国产存储芯片自给率目标40%
  • 国家大基金三期2,500亿元扶持
  • 中国占全球存储消费约35%，是全球最大市场
  • 阿里、字节、腾讯已启动与本土芯片厂商采购洽谈
关键判断：国产存储处于"从跟跑到并跑"的临界点。长鑫存储的HBM3样品交付华为，是国产HBM从0到1的里程碑。2027年40%自给率目标下，国产存储是中期确定性较强的方向。

07 投资逻辑与财务视角

7.1 存储周期的投资框架

1涨价启动期 → 2业绩兑现期 → 3估值抬升期 → 4见顶回落期

当前处于第2-3阶段（业绩兑现+估值抬升）：涨价已反映在业绩（2026E +134%），市场正交易"高位能保持多久"。

7.2 投资主线

主线一（涨价弹性）：存储原厂（SK海力士、三星、美光）与国内模组厂（江波龙、佰维存储）——DDR5/DDR4涨价直接增厚利润。

主线二（国产突破）：长鑫存储（拟IPO）、长江存储——HBM国产化+自给率40%目标，政策确定性强。

主线三（HBM链）：先进封装、设备、材料——HBM扩产带动产业链。

主线四（存储模组）：江波龙、佰维存储——绑定原厂长约，享受涨价红利。

7.3 财务视角

存储行业的核心财务指标：DRAM/NAND ASP（平均售价）、库存水平、毛利率拐点。本轮周期中，原厂毛利率从周期底部大幅回升，模组厂弹性更大但议价权弱。

一句话总结：存储是本轮AI周期中涨价弹性最大的环节，处于"业绩兑现+估值抬升"阶段。国产存储（长鑫HBM突破）提供中期增量逻辑。核心跟踪DDR5价格、HBM供需、英伟达GPU绑定。

08 风险因素与展望

风险一：周期见顶（中高风险）。2026Q3起合约价涨幅收窄（预计+3~8%），若2027年需求不及预期，价格可能见顶回落。历史存储周期下行时跌幅可达50%+。
风险二：涨价抑制需求（中风险）。存储涨价已传导至终端（手机、PC、服务器），高价可能抑制下游采购，需求端或出现"买涨不买跌"后的回调。
风险三：供给超预期释放（中风险）。三星罢工结束后产能恢复、原厂扩产计划落地，可能加速供需拐点到来。
风险四：估值风险（中风险）。SK海力士股价一年+275%、美光+239%，估值已计入乐观预期，周期股在景气高点往往估值最低点，需警惕"戴维斯双杀"。
