01 执行摘要

2026年被业界公认为人形机器人"量产元年"——产业从"概念验证"迈向"规模化起步"。本报告从市场规模、竞争格局、核心零部件、产业链价值分配、商业化路径、投资逻辑六个维度，对人形机器人/具身智能行业进行系统性分析。

核心结论一：2026年是人形机器人的量产元年。中国人形机器人市场预计突破200亿元，产量有望突破10万台。产业从"讲故事"进入"出产品"阶段。

核心结论二：中国主导全球供给——2025年全球出货1.44万台，中国占84.7%；TOP6厂商中中国占5家，合计占全球74.1%。宇树以5,500+台居全球第一。

核心结论三：核心零部件国产化率已超70%（谐波减速器、伺服电机超80%）。运动控制占机器人成本55%，是最值钱的环节；减速器单项占成本20-30%。

风险提示：成本高企、可靠性不足、商业化落地慢、估值泡沫（融资超200亿元）。

02 行业概览：量产元年

2.1 什么是人形机器人

人形机器人是外形和运动方式模仿人类的智能机器人，拥有"手、脚、脑"——灵巧手执行精细操作、双足实现移动、大模型赋予认知决策能力。其核心是"具身智能"：AI从数字世界进入物理世界。

2.2 为什么是2026

1大模型突破（AI大脑） → 2零部件国产化（70%+） → 3成本下降 → 4政策标准落地（工信部） → 5量产元年（2026）

2.3 政策标志

2026年2月，工信部发布《人形机器人与具身智能标准体系（2026版）》，这是我国首个覆盖全产业链、全生命周期的标准顶层设计。政策从"鼓励研发"进入"规范发展+推动应用"并重阶段。

核心逻辑：人形机器人是AI的"物理出口"——大模型解决了"思考"，人形机器人解决"行动"。当AI算力（我们已做的Day03-09系列）铺就了基础设施，人形机器人就是下一个承接AI价值的硬件载体。

3.3 远期空间

2030年具身智能相关市场规模预计达4,000亿元；2035年有望突破万亿元。出货量从2025年1.44万台到2029年35万台，单价从25万元降至16万元——量增价降，是典型的成长行业曲线。

关键判断人形机器人市场呈"小基数、高增速"特征——2026年200亿元看似不大，但5年20倍增长（到4000亿）的预期，是资本市场愿意给高估值的核心原因。

6.3 宇树G1拆解的启示

宇树G1拆解报告显示：核心硬件多为自研，宇树的核心竞争力在自研运控算法而非硬件。报告建议投资者关注关节模组、丝杠、减速器、轻量化材料、电机、传感器及设备等领域标的。

产业链判断整机厂（宇树/优必选/特斯拉）赚的是"品牌+算法"的钱；零部件厂（绿的谐波/双环/鸣志）赚的是"量产放量+国产替代"的钱。投资上，零部件环节的确定性高于整机（整机格局未定）。

07 商业化：从工厂到生活

7.1 落地场景演进

1工业（工厂质检/搬运） → 2物流（仓储分拣） → 3服务（药店/商超） → 4家庭（远期）

7.2 当前商业化案例

  • 特斯拉Optimus：弗里蒙特工厂执行零部件搬运、电池分装
  • 优必选Walker S：蔚来、东风柳汽工厂质检、装配辅助
  • Agility Digit：亚马逊物流仓储试点
  • 银河通用Galbot：药店、商超场景泛化抓取
  • 北京天工：人形机器人生产线上无人化装配

7.3 商业化挑战

行业核心挑战仍是三件事：成本、可靠性、泛化能力。当前单台售价20-65万元，要达到家庭普及需要降至2万美元（约14万元）以下——特斯拉的2万美元目标就是行业风向标。

投资含义：商业化落地顺序是"工业→物流→服务→家庭"。2026-2027看工业场景放量（工厂是刚需+付费能力强），家庭场景是远期故事。跟踪特斯拉Optimus量产进度是行业风向标。

08 投资逻辑与财务视角

8.1 资本热度

  • 2026年前两个月中国具身智能及机器人赛道融资超30起，合计约200亿元
  • 2026年Q1融资额同比增长近60%
  • 银河通用2026年3月完成25亿元A+轮，估值超200亿元（中国单笔最大机器人融资）
  • 2026年计划上市：宇树科技、银河通用、星海图、松延动力、乐聚

8.2 投资主线

主线一（减速器/运动控制）：绿的谐波（谐波国产龙头，获特斯拉订单）、双环传动（RV减速器）——价值量最高+国产替代确定性。

主线二（电机/丝杠）：鸣志电器、步科股份、禾川科技——单台用量大，跟随量产放量。

主线三（整机/融资标的）：宇树科技、优必选、智元——格局未定，弹性大风险也大。

主线四（传感器/激光雷达）：禾赛、速腾聚创——人形机器人增量方向。

8.3 财务视角

当前人形机器人行业整体处于"投入期"：整机厂（优必选等）多数尚未盈利，靠订单预期支撑估值；零部件厂（绿的谐波等）已有成熟业务（工业机器人零部件），人形机器人是增量期权。投资逻辑本质是"给2027-2030年的量产买单"。

一句话总结：人形机器人是2026年最硬的成长赛道——市场5年20倍（200亿→4000亿）、中国主导供给、零部件国产化70%+。投资上零部件确定性>整机弹性，核心跟踪特斯拉Optimus量产与国产零部件订单落地。

09 风险因素与展望

风险一：成本高企（中高风险）。当前单台售价20-65万元，距离家庭普及的2万美元目标仍有数倍差距。若成本下降不及预期，规模化进程将推迟。
风险二：可靠性不足（中高风险）。人形机器人需要在真实环境稳定运行，当前技术成熟度（TRL）仍处早期，工业场景的可靠性要求极高，量产落地可能不及预期。
风险三：估值泡沫（中风险）。2026年融资超200亿元、头部估值200亿+，行业尚无明显收入，估值已大幅透支未来。若量产不及预期，估值回调风险大。
风险四：竞争格局未定（中风险）。整机厂商格局尚未固化（特斯拉/宇树/优必选/Figure混战），押注单一整机标的风险高。
