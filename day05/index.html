02 行业概览：数据高速公路

2.1 光模块是什么

光模块是光通信的核心器件，负责将电信号转换为光信号（发射）和将光信号转换为电信号（接收），实现数据中心内部和之间的高速数据传输。在AI算力体系中，光模块是连接GPU服务器集群的"数据高速公路"。

2.2 在算力产业链中的位置

1AI芯片（算力） → 2服务器/PCB（算力容器） → 3光模块（数据传输） → 4智算中心（算力地产）

2.3 需求拉动逻辑

谷歌、亚马逊、微软、Meta持续建设AI数据中心 → 云厂商资本开支大幅提升 → AI算力集群增大使互联距离变长 → 高速光模块需求爆发。

核心逻辑：AI训练集群从万卡级向十万卡级扩展，光模块需求量呈倍数增长。每台AI服务器机架中光收发器是核心组件之一——算力越大，数据传输需求越强，光模块越受益。

3.2 Scale Up：更大的增量市场

光模块正从Scale Out（横向扩展）向Scale Up（纵向扩展）网络渗透。Scale Up市场空间是Scale Out的5-10倍——这是光模块行业最重要的增量逻辑。随着AI集群从万卡向十万卡扩展，Scale Up网络对高速光模块的需求将爆发式增长。

3.3 中国厂商的份额逻辑

中国光模块厂商已从"成本优势"转向"工程师红利+迭代效率"驱动——全球前10大厂商中中国大陆占7家，份额超60%。这是中国在AI硬件产业链中少有的"主场作战"环节。

关键判断与AI芯片（国产替代率低）不同，光模块是中国厂商已主导的环节。投资逻辑不是"替代"，而是"跟随AI资本开支放量"。

4.2 中国厂商的领先

2024年Q1中国厂商已率先推出1.6T硅光光模块，在硅光方案上领先全球。技术代际切换是中国光模块厂商保持全球竞争力的核心武器——每一代新产品都带来"需求、价格和利润同步提升"。

投资含义：光模块投资的本质是"跟代际"——每一代新技术（800G→1.6T→3.2T）量产，都带来一轮业绩释放。当前处于800G放量+1.6T上量的黄金窗口。

05 CPO：终极方向还是颠覆者

5.1 什么是CPO

CPO（Co-Packaged Optics，共封装光学）将光引擎与交换芯片直接集成在同一封装内，是光模块技术的终极演进方向。

5.2 核心优势

维度传统可插拔CPO提升
端口功耗（800G）约30W降至9W降低70%
能效18.75pJ/bit5.63pJ/bit提升3.3倍
电损耗约22dB降至4dB完整性提高63倍
离散光学组件—减少80%故障率降10倍

5.3 进展与影响

CPO处于早期产业化阶段，预计从1.6T时代开始在超大规模数据中心应用。英伟达2025年GTC推出基于CPO的Spectrum-X和Quantum-X交换机，采用台积电COUPE封装，Spectrum-X总吞吐量高达400Tbps（黄仁勋称"全垒打式创新"）。

替代影响：CPO是终极方向，将对传统可插拔光模块形成替代压力。但替代是渐进的——1.6T时代CPO与可插拔并存，且CPO将重构产业链价值分配，拥有光芯片自研能力的厂商（中际旭创、天孚通信等）在新格局中占优。

7.2 卡脖子的意义

光芯片是光模块产业链中少数仍被海外主导的环节（EML、InP激光芯片）。这既是风险（供给紧张），也是机会——国产光芯片替代是光模块行业的下一个增长极。

产业链启示：中际旭创自研硅光芯片是行业标杆——掌握上游芯片能力，才能在新代际（1.6T/CPO）竞争中掌握主动权。光芯片国产化是值得跟踪的中期逻辑。

8.2 投资逻辑

主线一（确定性龙头）：中际旭创——全球第一+深度绑定英伟达/谷歌/亚马逊，业绩确定性强，PE相对合理。

主线三（CPO受益）：天孚通信——上游无源器件+硅光引擎，CPO趋势下的确定性受益者。

主线四（光芯片）：Lumentum等——EML/InP卡脖子环节，供给紧张带来议价权。
一句话总结：光模块是中国在AI硬件产业链中已主导的环节（份额60%+），投资逻辑是"跟随AI资本开支放量"。龙头看确定性（中际旭创），弹性看新易盛，中长期看CPO与光芯片国产化。

09 风险因素与展望

风险一：CPO替代（中高风险）。CPO是终极方向，从1.6T时代开始在超大规模数据中心应用。若CPO渗透超预期，传统可插拔光模块厂商将面临价值重估。但CPO同样需要光引擎，有光芯片能力的厂商占优。
风险二：技术路线切换（中风险）。硅光、LPO、薄膜铌酸锂等路线并存，押错路线的厂商可能掉队。
风险三：客户集中（中风险）。光模块厂商收入高度依赖少数云厂商（北美大厂），一旦云厂商资本开支调整，业绩波动大。
风险四：估值风险（中风险）。龙头2026E PE已达45倍以上，市值一年涨4倍（中际旭创+401%、新易盛+435%），估值已计入高增长预期，一旦增速放缓回调风险大。
