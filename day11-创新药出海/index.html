01 执行摘要

2026年是中国创新药出海的"质变之年"——上半年BD交易总额超1,000亿美元，逼近2025年全年1,357亿美元的近八成，全球Top10 BD交易中国独占8席。本报告以2026年为基准，从市场全景、重磅交易、药企分化、模式质变、政策环境、投资逻辑六个维度展开。

核心结论二：交易结构质变——从"卖管线"到"研发能力互换"。石药-阿斯利康185亿（多肽平台）、恒瑞-BMS 152亿（双向授权）、信达-辉瑞105亿（肿瘤管线），Co-Co共同开发取代一次性权益转让。

核心结论三：百济神州以自主商业化证明"MNC级能力"（泽布替尼单季全球销售约76亿元），恒瑞给出2026年创新药收入增速超30%指引——出海从"讲故事"进入"看业绩"阶段。

风险提示：早期项目占比66%、里程碑付款打折、BD审美疲劳、自主商业化能力差距。

02 行业概览：出海进入新阶段

2.1 什么是License-out

License-out（对外授权）是中国创新药企将药物海外权益授权给跨国药企（MNC），由MNC负责海外开发与商业化。中国药企获得首付款、里程碑付款和销售分成。

2.2 三阶段演进

1卖管线（2021-2023） → 2放量元年（2025） → 3体系出海（2026）

2.3 2026年的标志性变化

  • 交易升级：从单品授权 → 管线打包、技术平台整体输出
  • 模式升级：从一次性权益转让 → Co-Co共同开发、权益互换
  • 路径升级：从License-out → 自主出海体系（百济、复宏汉霖）
核心逻辑：2026年创新药出海的关键词是"质变"——不仅交易金额创新高，交易结构也从"卖产品"转向"卖能力"。中国药企在全球医药价值链中的角色，从"被授权方"变成"技术供给方"。

3.2 全球地位

2026上半年全球Top10 BD交易中，中国独占8席（2025年同样8席）。中国已成为全球医药License-out交易的核心供给方，中国资产在全球的价值从"补充性购入"转向"战略性布局"。

美国仍是绝对核心，但欧洲药企（阿斯利康、GSK、赛诺菲、诺华）活跃度显著提升，出海对象从"美国化"向"全球化主流药企"扩展。

关键判断2026年上半年单笔超10亿美元交易23起、占总金额92%——头部集中效应极强，大单是拉动增长的核心动力。中小药企BD体量偏小（平均单笔1.4亿美元），分化明显。

4.3 交易结构的变化

以恒瑞-BMS为例：不再是"一锤子卖断"，而是4个恒瑞原研+4个BMS原研+5个共同研发的双向授权，从"卖管线"升级为"研发能力互换"。这是2026年出海交易最显著的结构变化。

投资含义：百亿级大单密集落地（石药、恒瑞、信达），验证中国创新药资产已获MNC战略性认可。但交易结构转向早期项目+共同开发，意味着里程碑兑现周期更长、不确定性更高。

05 主要药企：模式分化

恒瑞医药License-out+自研双线
2026年动态：BMS 152亿美元（史上最大BD）、GSK延续合作。业绩：2026年Q1创新药收入45.26亿元（+25.75%，占比61.69%）；2025年创新药收入163.42亿元（+26.09%，占药品收入58.34%）。指引：2026年创新药收入增速超30%。
百济神州自主出海标杆
验证：泽布替尼单季度全球销售约76亿元人民币——靠自有团队在美欧直销，不依赖BD。意义：坐稳中国制药业市值榜首，市场为"已获验证的自主商业化能力"定价。
康方生物双抗出海
2026年动态：2026.02授予济川药业伊喜宁（PCSK9）独家商业化权益（8,000万授权费）。核心：依沃西（PD-1/VEGF双抗）与Summit合作持续兑现，对比K药III期数据强阳性。
复宏汉霖体系出海
2026年突破：汉倍优（帕妥珠单抗）获批国内上市，叠加美国FDA、欧盟EMA批准，成为全球唯一由中国企业自主研发、中美欧三大主流市场同步获批的帕妥珠单抗。曲帕双靶组合成为首个中美欧三证齐全的国产方案。
石药集团GLP-1平台出海
2026年动态：与阿斯利康185亿美元长效多肽平台合作（首付12亿创近年新高）。意义：GLP-1/代谢领域成为中国继肿瘤之后的第二增长曲线。
格局判断：2026年药企分化明显——恒瑞/信达/石药走"大额BD+保留核心管线"路线，百济走"自主出海"路线，复宏汉霖走"体系出海"路线。市场定价逻辑也从"BD金额"转向"已验证的商业化能力"。

06 出海模式质变

维度2025年（放量元年）2026年（体系出海）
交易形态单品/管线授权管线打包、平台整体输出
合作模式一次性权益转让Co-Co共同开发、双向授权
项目阶段以临床中后期为主早期项目占比升至66%
区域布局美国为主美+欧（阿斯利康/GSK/诺华）
价值输出单品价值技术平台、成套方案、产业体系

西南证券指出：不同于2025年以明星管线挑大梁的BD，2026年石药、信达、恒瑞的交易正转向早期平台型输出——全球创新药分工正式进入"中国主导早期发现、全球负责后期开发"的新阶段。

模式判断出海模式的演进路径：License-out（卖权益）→ Co-Co共研（卖能力）→ 自主出海（卖体系）。百济神州、复宏汉霖代表"造船出海"的终极形态，恒瑞们代表"借船出海"的过渡形态。行业门槛已从研发资金，转向商业化体系搭建能力。

07 政策与监管环境

7.1 2026年政策要点

  • 2026年5月1日：国务院令第818号《生物医学新技术临床研究和临床转化应用管理条例》正式实施，CGT（细胞/基因治疗）产业进入"合规元年"
  • 2026年1月：阿美替尼等药品新增支付范围，信迪利单抗等扩大适应症报销
  • 2026版基药目录：净增109个品种，4款国产1类新药首次入围

7.2 2025年政策背景（延续影响）

  • 2025年12月医保目录新增114种药（含50种1类创新药）
  • 首版商保创新药目录纳入19种高值创新药（含5款CAR-T）
  • 化药集采已完成十批，边际影响减弱
政策判断：2026年政策主线是"支持创新+规范发展"并重——CGT条例落地开启细胞基因治疗合规元年，医保/基药目录持续纳入创新药。国内政策支持为创新药出海提供了"主场优势"和现金流底座。

08 投资逻辑与风险

8.1 投资逻辑

主线一（BD弹性+业绩兑现）：恒瑞医药——2026年创新药收入增速超30%指引+BMS大单，License收入持续落地。

主线二（自主出海验证）：百济神州——泽布替尼单季76亿元，自主商业化能力获市场定价。

主线三（平台/体系出海）：复宏汉霖（中美欧三证）、石药（GLP-1平台）、信达（辉瑞/礼来双大单）。

主线四（新技术平台）：小核酸、PROTAC、TCE、CAR-T、AI制药（英矽智能）。

8.2 风险提示

风险一：早期项目占比高（中高风险）。2026年Q1临床前至I期项目占比达66%，海外权益被更早授权——变现周期拉长、临床失败风险前置。
风险二：BD审美疲劳（中风险）。恒瑞官宣BMS交易当天股价几乎无反应——密集交易让投资人对BD公告的价格敏感度钝化，143亿美元里程碑被市场打折扣。
风险三：自主商业化能力差距（中风险）。百济已证明自主出海可行，但多数药企仍依赖MNC商业化——"借船出海"让渡利润大头。
风险四：监管与地缘（中风险）。FDA审批、中美关系波动可能影响生物医药合作。
一句话总结：2026年创新药出海从"卖管线"进入"体系出海"，市场定价逻辑从"BD金额"转向"商业化能力"。恒瑞看业绩指引兑现，百济看自主出海验证，复宏/石药看平台价值。

09 展望与跟踪信号

9.1 2026下半年展望

2026上半年BD总金额已逼近2025全年的八成，全年有望再创历史新高。但需关注：早期项目占比提升带来的里程碑兑现周期拉长，以及医药板块与BD热度背离（2026年医药板块持续跑输大盘近7个百分点）的估值压力。
